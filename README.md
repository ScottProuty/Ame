# Ame 雨
Ame (あめ, "rain") is a game made for practicing Japanese hiragana and katakana. 
The concept is simple: blocks fall (rain, if you will) into a cup. Type the romaji of each symbol displayed on those blocks to make them disappear. Each removed block awards points.
The goal is to play for as long as you can without letting a block overflow out of the cup. If a block reaches the bottom of the screen, it's game over.

### Examples of Romaji
**Japanese symbol**: *What to type*
**あ**: a
**を**: wo
**で**: de
**の**: no
**サ**: se
**ツ**: tsu
Watch out for へ and く, they can look alike when rotated!

## Settings
In the settings menu, you can choose which character sets you'd like to practice, between:
**Hiragana**
**Katakana**
**Hiragana Diacritics**
**Katakana Diacritics**

Diacritics, also known as *ten-ten* for Japanese, include *dakuten* (two small lines) and *handakuten* (a circle). They change the romaji like this:
**は**: ha
**ば**: ba
**ぱ**: pa
